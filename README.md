# 🧪 Advanced Periodic Table

An interactive and beautiful Periodic Table of all 118 elements with detailed information popup and search functionality.

## ✨ Features

- Complete 118 elements with proper grid layout
- Category-wise color coding
- Click on any element to see detailed information (Atomic mass, Category, etc.)
- Search by element name or symbol
- Smooth hover animations
- Clean and educational design

## 🚀 Live Demo

[→ Open Periodic Table](https://khushiprajapati01.github.io/advanced-periodic-table/ live demo).

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid + Hover Effects)
- Vanilla JavaScript

## How to Use

1. Visit the live link above
2. Browse the periodic table
3. Click on any element for detailed view
4. Use the search bar to quickly find elements
