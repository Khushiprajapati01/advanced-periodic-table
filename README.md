# 🧪 Advanced Periodic Table

An interactive and beautiful Periodic Table of all 118 chemical elements with detailed information on click.

![Periodic Table](https://via.placeholder.com/800x400/1a73e8/ffffff?text=Periodic+Table)

## ✨ Features

- Complete 118 elements with proper scientific layout
- Category-wise color coding (Alkali metals, Transition metals, Noble gases, etc.)
- Click on any element to view detailed information
- Search functionality (by name or symbol)
- Smooth hover animations
- Fully responsive design
- Clean and educational UI

## 🚀 Live Demo

[→ Open Periodic Table](https://khushiprajapati01.github.io/advanced-periodic-table/)

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid Layout + Animations)
- Vanilla JavaScript

## 📱 How to Use

1. Visit the live link above
2. Browse the periodic table
3. Click on any element to see its details (Atomic number, mass, category, etc.)
4. Use the search bar to quickly find any element

## 📚 About

This is an educational project made to understand grid layout, DOM manipulation, and interactive web design.
